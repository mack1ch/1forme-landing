# 1forme Landing

Одностраничный лендинг платформы 1forme для автоматизации фитнес-студий. Проект построен на Next.js, использует архитектуру Feature-Sliced Design, стилизацию через SCSS и компоненты Ant Design.

## Стек

- Next.js 13 (App Router)
- TypeScript
- SCSS Modules
- Ant Design
- Feature-Sliced Design

## Запуск проекта

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Скрипты

- `npm run dev` — запуск дев-сервера Next.js
- `npm run build` — сборка приложения для продакшена
- `npm run start` — запуск собранного приложения
- `npm run lint` — запуск встроенного линтера Next.js
